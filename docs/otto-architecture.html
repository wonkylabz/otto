Model gateway maps each phase — route · clarify · memory · verify · execution — to the cheapest capable model. Execution stays Claude.

About the tiles

The capability tiles are an example landscape — one team's agents and skills, not what Otto ships. Otto discovers whatever lives in your own ~/.claude; only the handful under capabilities/ come with it.

The point of the drawing is that the agents aren't peers of Otto — they run inside it. Otto is the connective tissue: ingress, routing, the write-approval gate, the verify loop, and the memory + audit trail are shared by every capability. So the lifecycle is open-ended: a new agent is a tile dropped into the registry, and it inherits routing, gating, verification and audit for free.
